## Current disposition

- [Source-level accessibility checks](../../../../../../packages/ui/src/a11y.test.tsx) inspect component source for ARIA attributes, keyboard handlers and focus-management patterns; they do not exercise keyboard behavior in a browser.
- [Token-contrast tests](../../../../../../packages/ui/src/contrast.test.ts) calculate contrast for selected CSS token pairs. Neither suite establishes a completed browser accessibility audit or WCAG certification.
- The current [operator setup guide](../../../../../operations/operator-setup.md) covers setup, configuration, branding, deployment and localization; the `docs/operator/*` paths below were proposed targets, not the current guide.
- The proposed axe installation/testing integration and route scans were not delivered as an audit and are not required by this superseded batch. An unused dependency entry is not an implemented audit.
- The [web lane of `bin/check`](../../../../../../scripts/lib/gate.ts) runs lint, typechecking, Bun tests and the web build; it does **not** run Playwright or an axe route scan.
